# Placement Tracker

A full-stack web application that helps users track and manage their job applications in one place.

## Features

- User Registration and Login
- JWT-based Authentication
- Add and Manage Job Applications
- Track Application Status
- Search Applications by Company
- Filter Applications by Status
- Sort Applications by Company and Role
- Multi-user Support
- Responsive User Interface

## Tech Stack

### Frontend
- React.js
- JavaScript
- HTML
- CSS

### Backend
- Python
- Flask
- Flask-CORS
- JWT Authentication

### Database
- SQLite

## Architecture

Frontend (React) → REST APIs (Flask) → SQLite Database

The application follows a client-server architecture where the React frontend communicates with Flask REST APIs, and the backend handles business logic, authentication, and database operations.

## Authentication

JWT (JSON Web Token) is used for secure user authentication and authorization. Protected routes can only be accessed by authenticated users.

## Project Features

### User Management
- Register new users
- Secure login using JWT authentication
- Logout functionality

### Application Tracking
- Add job applications
- View all applications
- Track application status
- Search applications
- Filter by status
- Sort by company and role

## Deployment

The application is deployed on Replit and can be accessed online through a public URL.
